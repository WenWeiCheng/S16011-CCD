

## FPGA 硬件平台

### CCD 模块

只管 CCD 的移位时序产生、数据缓存、数据发送，曝光时间由其它控制（比如计时器）。

时序逻辑：接收一个曝光结束信息，然后开始对像素进行移位读出。同时控制 ADC 对读出的模拟信号进行采样，解析输出数据，去掉bevel像素，保留暗像素和感光像素信号，数据存在 ram 中。

输入接口：

- 复位：同时清除缓存帧

- 曝光信号：下降沿开始电荷读出、模数转换、数据解析和缓存
- 图像高度 (16bit)：
- 图像宽度 (16bit)：
- 斜边像素 (16bit)：上下左右的数量
- 空白像素 (4bit)：左右数目
- 读出模式 (2bit)：area scan, line binning
- 垂直合并 (16bit)：垂直合并行数
- vertical-binning-offset (16bit)：垂直合并偏移
- 读出帧：下降沿启动一帧数据的读出

输出接口：

- USB 控制器 FIFO 接口
- 缓存帧数目
- CCD读出状态：空闲/忙
- 缓存读出状态：空闲/忙



存储帧长度、帧数等信息。接收帧发送指令，将一帧数据通过 FIFO 接口把数据发给 USB 控制器的 FIFO
